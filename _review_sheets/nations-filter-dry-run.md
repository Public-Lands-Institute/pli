# Native Land nation filter: dry run

97 sites. Old rule: union of record nations and every Native Land polygon containing the site. New rule: a Native Land nation is kept only where the site's native_lands or displacement_tenure text names it (name or common alternate); record nations are always kept. The Royce cession test is not applied because the pipeline has no Royce cession geometry. Cultures are unchanged and not listed.
